# Homebase Carehold boundary
Adult, explicit, temporary schedule-summary consent only. Source uses the same Today ledger visibility query, which respects role, profile grants, adult self and full-circle caregiver policy. Homebase receives two numbers and a fixed ten-minute expiry, no person or medication identifiers, dose, history, event status, note, journal, message, recovery material, passkey or session token. No writes or clinical action. Unrecorded is not missed. The source verifies the exact session ID (never exports it), current session expiry, passkey enrollment, membership and adult classification on redemption and every read. Source logout/revocation invalidates immediately on next read; source tab auto-lock is intentionally separate and does not itself revoke a browser-wide session. The fixed consent lease never refreshes. Homebase must clear on hidden/offline/expiry and provide links to standalone Carehold with its own unlock/recovery. No sensitive data in Today/activity/push. No trusted-device migration; PR #12 is independent and remains unmerged. 
Local config uses independent D1, no scheduled triggers or VAPID, launcher-generated secret and isolated fixture pilot code. No production data or credentials. No deployment. Manual verification policy remains unchanged.
